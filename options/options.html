How It Works

Why is this extension needed?

Google Docs only saves the "Display word count while typing" setting on a per-document basis. Whenever you create a new document (e.g. via docs.new) or open documents created by others, the word count is turned off by default. Google provides no account-level global switch for this.

How does this extension turn it on?

When you open a Google Doc, the extension checks if the native word count pill is already visible. If not, it automatically and silently activates the native setting via Google Docs' built-in Word Count tool. Because it uses Google Docs' native feature, the word count is 100% accurate, tracks text as you type, and allows you to click the counter to switch between words, pages, and characters.

Does this extension track or collect any data?

No. The extension runs 100% locally inside your browser. No analytics, no remote servers, no data collection. It only interacts with the Google Docs interface to toggle your preferred display setting.

Keyboard Shortcut

You can also manually open the native Google Docs Word Count box at any time by pressing Ctrl + Shift + C (Windows/Linux/ChromeOS) or Cmd + Shift + C (Mac).
